1. Introduction to Programming

Programming is the process of writing instructions that tell a computer how to perform a task.

A programming language provides a way for humans to communicate instructions to a computer.

Examples: C, C++, Java, Python and JavaScript.

2. Introduction to C Programming

C is a general-purpose programming language widely used for system programming, embedded systems and learning programming fundamentals.

Features of C

  • Simple and efficient
  • Structured programming
  • Portable
  • Fast execution
  • Supports functions
  • Rich set of operators

3. Basic Structure of a C Program

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

The main() function is the starting point of execution in a C program.

4. int main()

The main() function is where program execution begins. The return type int indicates that the function returns an integer value. 

int main()
{
    return 0;
}

5. printf() Function

The printf() function is used to display output on the screen. It is declared in the stdio.h header file. 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

6. Variables

A variable is a named memory location used to store a value. Its value can change during program execution. 

int age = 18;
float marks = 85.5;
char grade = 'A';

7. Data Types

  • int — Integer values
  • float — Decimal values
  • double — More precise decimal values
  • char — Single character
int a = 10;
float b = 5.5;
char c = 'A';

8. Input Using scanf()

The scanf() function is used to take input from the user. 

#include <stdio.h>

int main()
{
    int age;

    printf("Enter age: ");
    scanf("%d", &age);

    printf("Age = %d", age);

    return 0;
}

9. Operators in C

Arithmetic Operators

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus

Relational Operators

  • > Greater than
  • < Less than
  • >= Greater than or equal
  • <= Less than or equal
  • == Equal to
  • != Not equal

Logical Operators

  • && AND
  • || OR
  • ! NOT

10. if-else Statement

The if-else statement is used for decision making. 

#include <stdio.h>

int main()
{
    int age;

    printf("Enter age: ");
    scanf("%d", &age);

    if(age >= 18)
    {
        printf("Eligible");
    }
    else
    {
        printf("Not Eligible");
    }

    return 0;
}

11. Loops

Loops are used to execute a block of code repeatedly.

for Loop

for(int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

while Loop

int i = 1;

while(i <= 5)
{
    printf("%d ", i);
    i++;
}

12. Arrays

An array is a collection of elements of the same data type stored under one name. 

int numbers[5] = {10,20,30,40,50};

13. Functions

A function is a block of code designed to perform a specific task. Functions help make programs modular and reusable. 

#include <stdio.h>

void hello()
{
    printf("Hello");
}

int main()
{
    hello();

    return 0;
}

14. Practice Programs

Program 1: Print Hello World

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Program 2: Add Two Numbers

#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Program 3: Check Even or Odd

#include <stdio.h>

int main()
{
    int n;

    printf("Enter number: ");
    scanf("%d", &n);

    if(n % 2 == 0)
        printf("Even");
    else
        printf("Odd");

    return 0;
}

Program 4: Print Table

#include <stdio.h>

int main()
{
    int n;

    printf("Enter number: ");
    scanf("%d", &n);

    for(int i = 1; i <= 10; i++)
    {
        printf("%d x %d = %d\n", n, i, n*i);
    }

    return 0;
}

15. Important Questions with Answers

Q1. What is programming?

Programming is the process of writing instructions for a computer to perform a particular task.

A loop repeatedly executes a block of statements while its condition or loop control requires it.

Q6. What is an array?

Q7. What is a function?
