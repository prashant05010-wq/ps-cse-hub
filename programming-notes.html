Programming Notes

Programming fundamentals explained in simple language.

1. What is Programming?

Programming is the process of writing instructions that tell a computer how to perform a particular task.

Simple idea: Program = Instructions given to a computer.

2. Algorithm

An algorithm is a step-by-step procedure used to solve a particular problem.

Example: Add Two Numbers

  1. Start
  2. Take two numbers
  3. Add the numbers
  4. Display the result
  5. Stop

3. Flowchart

A flowchart is a graphical representation of an algorithm. It uses different symbols to represent different operations.

  • Oval → Start / Stop
  • Parallelogram → Input / Output
  • Rectangle → Process
  • Diamond → Decision

4. Variables

A variable is a named memory location used to store data that can change during program execution.

Example in C

int age = 18; float marks = 75.5; char grade = 'A';

5. Data Types

Data types specify the type of data that a variable can store.

  • int → Integer numbers
  • float → Decimal numbers
  • double → Larger decimal values
  • char → Single character

6. Operators

Arithmetic Operators

  • +
  • -
  • *
  • /
  • %

Relational Operators

  • ==
  • !=
  • >
  • <
  • >=
  • <=

Logical Operators

  • &&
  • ||
  • !

7. If-Else

The if-else statement is used to make decisions in a program.

#include <stdio.h> int main() { int age; printf("Enter age: "); scanf("%d", &age); if(age >= 18) { printf("Adult"); } else { printf("Minor"); } return 0; }

8. Switch Statement

The switch statement is useful when one value needs to be compared with multiple possible cases.

switch(choice) { case 1: printf("One"); break; case 2: printf("Two"); break; default: printf("Invalid choice"); }

9. Loops

Loops are used to execute a block of code repeatedly.

Types of Loops

  • for loop
  • while loop
  • do-while loop

Example: for Loop

for(int i = 1; i <= 5; i++) { printf("%d\n", i); }

10. Functions

A function is a block of code designed to perform a specific task. Functions help make programs organized and reusable.

int add(int a, int b) { return a + b; }

11. Arrays

An array is a collection of elements of the same data type stored under one name.

int marks[5] = {70, 75, 80, 85, 90};

12. Strings

A string is a sequence of characters. In C, strings are stored using character arrays.

char name[] = "Prashant";

13. Pointers

A pointer is a variable that stores the memory address of another variable.

int x = 10; int *p = &x;

14. Practice Questions

  1. Write a program to add two numbers.
  2. Write a program to check even or odd.
  3. Find the largest of three numbers.
  4. Print the multiplication table of a number.
  5. Find the factorial of a number.
  6. Check whether a number is prime.
  7. Reverse a number.
  8. Check whether a number is palindrome.
  9. Print Fibonacci series.
  10. Calculate grade according to marks.
