1. Introduction to Computer

A computer is an electronic device that accepts data as input, processes it according to instructions, stores information and produces useful output.

Basic Working: Input → Processing → Output → Storage

2. Characteristics of Computer

  • High Speed
  • Accuracy
  • Diligence
  • Large Storage Capacity
  • Automation
  • Versatility
  • Reliability

3. Generations of Computer

First Generation

Used vacuum tubes. These computers were very large and consumed a lot of electricity.

Second Generation

Transistors replaced vacuum tubes, making computers smaller, faster and more reliable.

Third Generation

Integrated Circuits (ICs) were introduced.

Fourth Generation

Microprocessors were introduced and personal computers became common.

Fifth Generation

Focuses on advanced technologies such as artificial intelligence, natural language processing and parallel processing.

4. Types of Computer

  • Supercomputer
  • Mainframe Computer
  • Minicomputer
  • Microcomputer
  • Desktop Computer
  • Laptop
  • Tablet
  • Smartphone

5. CPU — Central Processing Unit

CPU is often called the brain of the computer. It executes instructions and performs processing operations.

Main Parts of CPU

  • ALU — Arithmetic Logic Unit
  • CU — Control Unit
  • Registers
ALU: Performs arithmetic and logical operations.
CU: Controls and coordinates computer operations.
Registers: Small, high-speed storage locations inside the CPU.

6. Computer Memory

Memory is used to store data, instructions and results.

Primary Memory

  • RAM
  • ROM
  • Cache Memory

Secondary Memory

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card

7. RAM and ROM

RAM ROM
Volatile Memory Non-Volatile Memory
Data is lost when power is removed Data is retained without power
Used for temporary working data Stores firmware/instructions

8. Input Devices

Input devices are used to enter data and instructions into a computer.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam
  • Touchscreen

9. Output Devices

Output devices present processed information to the user.

  • Monitor
  • Printer
  • Speaker
  • Projector
  • Headphones

10. Hardware and Software

Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

Examples: Keyboard, mouse, monitor, CPU and motherboard.

Software

Software is a collection of programs and instructions that tell a computer what to do.

Examples: Operating systems, web browsers and applications.

11. Operating System

An operating system is system software that manages computer hardware and provides services for application programs.

Examples

  • Windows
  • Linux
  • macOS
  • Android
  • iOS

12. Functions of Operating System

  • Process Management
  • Memory Management
  • File Management
  • Device Management
  • Security
  • User Interface

13. Number System

A number system is a method of representing numbers using a specific set of digits and a base.

  • Binary — Base 2
  • Octal — Base 8
  • Decimal — Base 10
  • Hexadecimal — Base 16
Example: Decimal 10 = Binary 1010

14. Important Units of Memory

  • 1 Bit = 0 or 1
  • 1 Byte = 8 Bits
  • 1 KB = 1024 Bytes
  • 1 MB = 1024 KB
  • 1 GB = 1024 MB
  • 1 TB = 1024 GB
