Computer Fundamentals

Complete beginner-friendly notes for CSE students.

1. What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to instructions, stores information and produces useful output.

Simple Formula:
Input → Processing → Output

2. Characteristics of Computer

  • Speed: Performs operations very quickly.
  • Accuracy: Produces accurate results when correct instructions are given.
  • Storage: Stores large amounts of data.
  • Diligence: Can perform repetitive tasks without getting tired.
  • Automation: Performs tasks automatically after receiving instructions.
  • Versatility: Can perform many different types of tasks.

3. Types of Computers

Supercomputer

Very powerful computers used for scientific research, weather forecasting and complex calculations.

Mainframe Computer

Used by large organizations to process huge amounts of data and support many users.

Personal Computer

Computers designed for individual users, such as desktops and laptops.

Embedded Computer

Computers built into other devices such as cars, washing machines and smart devices.

4. Hardware and Software

Hardware

Hardware means the physical components of a computer that can be seen and touched.

  • Keyboard
  • Mouse
  • Monitor
  • CPU
  • RAM
  • SSD / Hard Disk

Software

Software is a collection of programs and instructions that tell the computer what to do.

  • Operating System
  • Web Browser
  • Media Player
  • Programming Software

5. CPU

CPU stands for Central Processing Unit. It processes instructions and controls the operations of the computer.

ALU

Arithmetic Logic Unit performs arithmetic and logical operations.

CU

Control Unit controls and coordinates different operations of the computer.

Registers

Registers are very fast small storage locations inside the processor.

6. Memory

Primary Memory

Primary memory is directly accessible by the CPU. RAM and ROM are examples.

RAM

RAM stands for Random Access Memory. It temporarily stores data and instructions currently being used.

ROM

ROM stands for Read Only Memory. It stores information that generally remains available even after power is removed.

Secondary Memory

Used for long-term storage of data. Examples include SSD, HDD, pen drives and memory cards.

7. Input Devices

Input devices are used to enter data and instructions into a computer.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam
  • Touchscreen

8. Output Devices

Output devices display or provide the result produced by a computer.

  • Monitor
  • Printer
  • Speaker
  • Projector
  • Headphones

9. Operating System

An Operating System, or OS, is system software that manages computer hardware and provides services to application programs.

Examples

  • Windows
  • Linux
  • macOS
  • Android
  • iOS

10. Number Systems

A number system is a method used to represent numbers. Computers mainly use the binary number system.

  • Binary: Base 2 — 0, 1
  • Decimal: Base 10 — 0 to 9
  • Octal: Base 8 — 0 to 7
  • Hexadecimal: Base 16 — 0 to 9 and A to F

11. Generations of Computers

  1. First Generation: Vacuum Tubes
  2. Second Generation: Transistors
  3. Third Generation: Integrated Circuits
  4. Fourth Generation: Microprocessors
  5. Fifth Generation: Advanced computing and AI-oriented technologies

12. Important Exam Questions

  1. What is a computer?
  2. Explain the characteristics of a computer.
  3. What is CPU? Explain its components.
  4. Differentiate between hardware and software.
  5. What is RAM and ROM?
  6. Explain primary and secondary memory.
  7. What is an operating system?
  8. Explain different types of computers.
  9. What are input and output devices?
  10. Explain different number systems.
