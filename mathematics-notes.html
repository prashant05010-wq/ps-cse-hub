1. Matrices

A matrix is a rectangular arrangement of numbers or elements in rows and columns.

A = [ a b ] [ c d ]

Types of Matrices

  • Row Matrix
  • Column Matrix
  • Square Matrix
  • Diagonal Matrix
  • Identity Matrix
  • Zero Matrix

2. Matrix Addition

Two matrices can be added when they have the same order. Corresponding elements are added.

Example:

A = [1 2]
    [3 4]

B = [5 6]
    [7 8]

A + B = [6 8]
      [10 12]

3. Determinant of a 2 × 2 Matrix

|a b| |c d| = ad - bc
Example:

A = [2 3]
    [1 4]

|A| = (2 × 4) - (3 × 1)

|A| = 8 - 3 = 5

4. Inverse of a Matrix

For a 2 × 2 matrix:

A = [a b] [c d] A⁻¹ = 1/(ad-bc) [ d -b ] [ -c a ]

The inverse exists when the determinant is not zero.

5. Eigenvalues

Eigenvalues of a square matrix are obtained from the characteristic equation.

|A - λI| = 0
Example:

For a simple matrix, form the characteristic equation and solve it to obtain the values of λ.

6. Eigenvectors

For an eigenvalue λ, the corresponding eigenvector X satisfies:

AX = λX

or equivalently:

(A - λI)X = 0

7. Differential Calculus

Differentiation measures the rate at which one quantity changes with respect to another.

d/dx (xⁿ) = n xⁿ⁻¹

Important Rules

  • d/dx(c) = 0
  • d/dx(x) = 1
  • d/dx(xⁿ) = n xⁿ⁻¹
  • d/dx(sin x) = cos x
  • d/dx(cos x) = -sin x
  • d/dx(eˣ) = eˣ

8. Example of Differentiation

Find the derivative of:

y = x³ + 2x² + 5x

Differentiate each term:

dy/dx = 3x² + 4x + 5
Answer: 3x² + 4x + 5

9. Integration

Integration is the reverse process of differentiation.

∫xⁿ dx = xⁿ⁺¹/(n+1) + C

Important Formulas

  • ∫1 dx = x + C
  • ∫x dx = x²/2 + C
  • ∫eˣ dx = eˣ + C
  • ∫sin x dx = -cos x + C
  • ∫cos x dx = sin x + C

10. Example of Integration

Find:

∫(3x² + 2x) dx

Integrating term by term:

= x³ + x² + C
Answer: x³ + x² + C

11. Differential Equations

A differential equation is an equation involving derivatives of an unknown function.

Example

dy/dx = 2x

Integrating both sides:

y = x² + C

12. Important Mathematical Formulas

(a - b)² = a² - 2ab + b²
a² - b² = (a-b)(a+b)
