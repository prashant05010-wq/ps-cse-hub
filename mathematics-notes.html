Engineering Mathematics

Important mathematics concepts and formulas for BTech CSE students.

1. Matrices

A matrix is a rectangular arrangement of numbers or elements in rows and columns.

Example

A = [ 1 2 3 4 ]

The matrix above has 2 rows and 2 columns, so its order is 2 × 2.

Important Types

  • Row Matrix
  • Column Matrix
  • Square Matrix
  • Diagonal Matrix
  • Identity Matrix
  • Zero Matrix

2. Determinants

A determinant is a scalar value associated with a square matrix.

For a 2 × 2 Matrix

| a b | | c d | Determinant = ad - bc
Example:
For | 2 3 |
    | 1 4 |

Determinant = (2 × 4) - (3 × 1) = 5

3. Limits

A limit describes the value that a function approaches as the input approaches a particular value.

lim x→a f(x)

Limits are an important foundation for calculus.

4. Differentiation

Differentiation is used to find the rate of change of a function.

Basic Formulas

d/dx (xⁿ) = n xⁿ⁻¹ d/dx (sin x) = cos x d/dx (cos x) = -sin x d/dx (eˣ) = eˣ d/dx (ln x) = 1/x

5. Integration

Integration is the reverse process of differentiation and is used to calculate areas and many other quantities.

Basic Formulas

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C ∫ 1/x dx = ln|x| + C ∫ sin x dx = -cos x + C ∫ cos x dx = sin x + C ∫ eˣ dx = eˣ + C

6. Differential Equations

A differential equation is an equation involving a function and one or more of its derivatives.

Example

dy/dx = 2x

Integrating both sides gives:

y = x² + C

7. Vector Basics

A vector is a quantity that has both magnitude and direction.

Examples

  • Velocity
  • Force
  • Displacement
  • Acceleration

Vector Form

A = ai + bj + ck

8. Important Mathematics Formulas

(a + b)² = a² + 2ab + b² (a - b)² = a² - 2ab + b² a² - b² = (a-b)(a+b) sin²x + cos²x = 1 1 + tan²x = sec²x 1 + cot²x = cosec²x

9. Practice Questions

  1. Find the determinant of a 2 × 2 matrix.
  2. Find the derivative of x³ + 2x² + 5.
  3. Integrate 3x² + 4x.
  4. Solve a simple first-order differential equation.
  5. Find the order of a given matrix.
  6. Evaluate basic limits.
  7. Simplify trigonometric identities.
  8. Find the magnitude of a vector.
