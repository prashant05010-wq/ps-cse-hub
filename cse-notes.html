Computer Fundamentals

Complete beginner-friendly notes for CSE students.

1. What is a Computer?

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information and produces useful output.

Simple definition: A computer takes Input → Processes it → Gives Output.

2. Characteristics of a Computer

  • Speed: A computer can perform millions of operations very quickly.
  • Accuracy: It can produce highly accurate results when the instructions and data are correct.
  • Storage: Computers can store large amounts of information.
  • Diligence: A computer does not become tired while performing repetitive tasks.
  • Automation: Once programmed, many tasks can be performed automatically.
  • Versatility: Computers can perform many different types of tasks.

3. Types of Computers

Supercomputer

Supercomputers are extremely powerful computers used for complex calculations, scientific research and simulations.

Mainframe Computer

Mainframe computers are designed to handle large amounts of data and many users simultaneously.

Personal Computer

Personal computers include desktops and laptops commonly used by individuals.

Embedded Computer

Embedded computers are built into devices such as cars, washing machines, cameras and other electronic systems.

4. Hardware and Software

Hardware

Hardware refers to the physical components of a computer that we can see and touch.

  • Keyboard
  • Mouse
  • Monitor
  • CPU
  • RAM
  • Hard Disk / SSD

Software

Software is a collection of programs and instructions that tell the computer what to do.

  • Operating Systems
  • Web Browsers
  • Text Editors
  • Media Players
  • Programming Software

5. CPU

CPU stands for Central Processing Unit. It is one of the most important components of a computer and performs processing and control operations.

Main Parts of CPU

  • ALU: Arithmetic Logic Unit performs arithmetic and logical operations.
  • CU: Control Unit controls and coordinates computer operations.
  • Registers: Very fast small storage locations inside the processor.

6. Computer Memory

Primary Memory

Primary memory is directly accessible by the CPU. Examples include RAM and ROM.

RAM

RAM stands for Random Access Memory. It temporarily stores data and instructions being used by the computer.

ROM

ROM stands for Read Only Memory. It stores information that generally remains available even when power is removed.

Secondary Storage

Secondary storage is used for long-term storage of data. Examples include HDD, SSD, memory cards and pen drives.

7. Input Devices

Input devices are used to enter data and instructions into a computer.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam
  • Touchscreen

8. Output Devices

Output devices present processed information to the user.

  • Monitor
  • Printer
  • Speaker
  • Projector
  • Headphones

9. Operating System

An Operating System, or OS, is system software that manages computer hardware and provides services for applications.

Examples

  • Windows
  • Linux
  • macOS
  • Android
  • iOS

10. Number System Basics

Number systems are methods of representing numbers. Computers commonly use the binary number system.

  • Binary: Base 2 — digits 0 and 1
  • Decimal: Base 10 — digits 0 to 9
  • Octal: Base 8 — digits 0 to 7
  • Hexadecimal: Base 16 — digits 0 to 9 and A to F

11. Generations of Computers

  1. First Generation: Vacuum tubes
  2. Second Generation: Transistors
  3. Third Generation: Integrated Circuits
  4. Fourth Generation: Microprocessors
  5. Fifth Generation: Advanced computing technologies including AI-oriented systems

12. Important Exam Questions

  1. What is a computer?
  2. Explain the characteristics of a computer.
  3. What is CPU? Explain its components.
  4. Differentiate between hardware and software.
  5. What is RAM and ROM?
  6. Explain primary and secondary memory.
  7. What is an operating system?
  8. Explain different types of computers.
  9. What are input and output devices?
  10. Explain binary, decimal, octal and hexadecimal number systems.
