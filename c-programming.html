C Programming

Learn C Programming from the basics with simple explanations and practical programs.

1. Introduction to C

C is a general-purpose programming language. It is widely used for learning programming fundamentals, system programming and many other applications.

Why learn C?

  • Easy to understand programming fundamentals
  • Fast and efficient
  • Useful for learning data structures
  • Helps build strong programming logic

2. Your First C Program

The classic first program prints "Hello World". 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Important parts

  • #include <stdio.h> → provides input/output functions.
  • main() → execution starts here.
  • printf() → displays output.
  • return 0; → ends the program successfully.

3. Variables & Data Types

Variables store data in a program. 

#include <stdio.h>

int main()
{
    int age = 18;
    float marks = 85.5;
    char grade = 'A';

    printf("%d\n", age);
    printf("%.2f\n", marks);
    printf("%c\n", grade);

    return 0;
}

Common data types

  • int → Integer numbers
  • float → Decimal numbers
  • char → Single character
  • double → Larger decimal values

4. Taking Input

The scanf() function is commonly used to take input. 

#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("You entered: %d", number);

    return 0;
}

5. If-Else

If-else is used when a program needs to make a decision. 

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if(age >= 18)
    {
        printf("You are eligible.");
    }
    else
    {
        printf("You are not eligible.");
    }

    return 0;
}

6. Loops

Loops are used to repeat a block of code.

For Loop Example

#include <stdio.h>

int main()
{
    int i;

    for(i = 1; i <= 10; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}

Program 6: Factorial of a Number

#include <stdio.h>

int main()
{
    int n, i;
    long long fact = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    for(i = 1; i <= n; i++)
    {
        fact = fact * i;
    }

    printf("Factorial = %lld", fact);

    return 0;
}

🚀 C Programming Mini Projects

🧮 1. Simple Calculator

Create a simple calculator that can perform addition, subtraction, multiplication and division. 


#include <stdio.h>

int main()
{
    float a, b;
    char op;

    printf("Enter first number: ");
    scanf("%f", &a);

    printf("Enter operator (+ - * /): ");
    scanf(" %c", &op);

    printf("Enter second number: ");
    scanf("%f", &b);

    switch(op)
    {
        case '+':
            printf("Result = %.2f", a + b);
            break;

        case '-':
            printf("Result = %.2f", a - b);
            break;

        case '*':
            printf("Result = %.2f", a * b);
            break;

        case '/':
            if(b != 0)
                printf("Result = %.2f", a / b);
            else
                printf("Cannot divide by zero");
            break;

        default:
            printf("Invalid operator");
    }

    return 0;
}

🏦 5. Simple Bank Management

A basic program to deposit, withdraw and display balance. 


#include <stdio.h>

int main()
{
    float balance = 1000;
    float amount;
    int choice;

    printf("1. Deposit\n");
    printf("2. Withdraw\n");
    printf("3. Check Balance\n");

    printf("Enter choice: ");
    scanf("%d", &choice);

    if(choice == 1)
    {
        printf("Enter amount: ");
        scanf("%f", &amount);

        balance = balance + amount;

        printf("Balance = %.2f", balance);
    }
    else if(choice == 2)
    {
        printf("Enter amount: ");
        scanf("%f", &amount);

        if(amount <= balance)
        {
            balance = balance - amount;
            printf("Balance = %.2f", balance);
        }
        else
        {
            printf("Insufficient balance");
        }
    }
    else if(choice == 3)
    {
        printf("Balance = %.2f", balance);
    }
    else
    {
        printf("Invalid choice");
    }

    return 0;
}

📊 6. Student Result System

Calculate total marks, percentage and grade of a student. 


#include <stdio.h>

int main()
{
    float m1, m2, m3;
    float total, percentage;

    printf("Enter marks of 3 subjects: ");
    scanf("%f %f %f", &m1, &m2, &m3);

    total = m1 + m2 + m3;
    percentage = total / 3;

    printf("Total = %.2f\n", total);
    printf("Percentage = %.2f%%\n", percentage);

    if(percentage >= 75)
        printf("Grade A");
    else if(percentage >= 60)
        printf("Grade B");
    else
        printf("Grade C");

    return 0;
}
