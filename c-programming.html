C Programming

Learn C Programming from the basics with simple explanations and practical programs.

1. Introduction to C

C is a general-purpose programming language. It is widely used for learning programming fundamentals, system programming and many other applications.

Why learn C?

  • Easy to understand programming fundamentals
  • Fast and efficient
  • Useful for learning data structures
  • Helps build strong programming logic

2. Your First C Program

The classic first program prints "Hello World". 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Important parts

  • #include <stdio.h> → provides input/output functions.
  • main() → execution starts here.
  • printf() → displays output.
  • return 0; → ends the program successfully.

3. Variables & Data Types

Variables store data in a program. 

#include <stdio.h>

int main()
{
    int age = 18;
    float marks = 85.5;
    char grade = 'A';

    printf("%d\n", age);
    printf("%.2f\n", marks);
    printf("%c\n", grade);

    return 0;
}

Common data types

  • int → Integer numbers
  • float → Decimal numbers
  • char → Single character
  • double → Larger decimal values

4. Taking Input

The scanf() function is commonly used to take input. 

#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("You entered: %d", number);

    return 0;
}

5. If-Else

If-else is used when a program needs to make a decision. 

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if(age >= 18)
    {
        printf("You are eligible.");
    }
    else
    {
        printf("You are not eligible.");
    }

    return 0;
}

6. Loops

Loops are used to repeat a block of code.

For Loop Example

#include <stdio.h>

int main()
{
    int i;

    for(i = 1; i <= 10; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}
